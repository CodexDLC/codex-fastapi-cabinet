# codex-fastapi-cabinet

`codex-fastapi-cabinet` помогает собирать кабинеты управления для FastAPI-сайтов и API из
небольших проверяемых деклараций.

Библиотека занимает промежуточное положение:

- даёт больше структуры, чем копирование роутов и шаблонов между проектами;
- не привязывается к ORM и не генерирует бизнес-CRUD автоматически.

Библиотека отвечает за переиспользуемую оболочку. Проект отвечает за прикладные сценарии.

## Возможности

- Независимые модули управления в `CabinetSite`, привязанном к приложению.
- Дашборды из метрик, таблиц, списков и диаграмм.
- Универсальные страницы списка, карточки, формы и операций.
- Асинхронные провайдеры данных на стороне проекта.
- Проверка прав без зависимости от конкретной системы аутентификации.
- Переопределение любого встроенного Jinja-шаблона.
- Явная загрузка модулей без побочных эффектов при импорте.
