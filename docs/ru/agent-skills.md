# Навык агента для проектов-потребителей

Пакет содержит необязательный автономный навык для агента, который работает с `codex-fastapi-cabinet` в FastAPI-приложении. Запускайте команды из Python-окружения с установленной библиотекой:

```bash
python -m fastapi_cabinet.agent_skills install --project D:\work\my-app
python -m fastapi_cabinet.agent_skills status --project D:\work\my-app
```

Аргумент `--project` обязателен и указывает на существующий каталог проекта. Установщик копирует навык в `.agents/skills/codex-fastapi-cabinet/`, записывает версию пакета и SHA-256 файлов в `.manifest.json`, добавляет ограниченный маркерами блок в корневой `AGENTS.md`. Правила проекта вне блока сохраняются. Сеть и запуск FastAPI-приложения не нужны.

После обновления библиотеки навык обновляется отдельной командой:

```bash
python -m fastapi_cabinet.agent_skills update --project D:\work\my-app
python -m fastapi_cabinet.agent_skills status --project D:\work\my-app
```

Удаление управляемых файлов и блока:

```bash
python -m fastapi_cabinet.agent_skills delete --project D:\work\my-app
```

`status` возвращает код `0`, только если версия, файлы и блок соответствуют установленному пакету. При отсутствии навыка, устаревшей версии или повреждении код равен `1`. Повторный `install` актуального навыка безопасен. `update` и `delete` отказываются заменять или удалять изменённые либо отсутствующие управляемые файлы. Сохраните свои изменения отдельно и держите правила приложения в отдельном проектном навыке. Столкновения с чужими файлами, символьные ссылки и точки повторной обработки Windows блокируются. При обычной ошибке записи выполняется попытка отката; гарантии восстановления после аварийного завершения или одновременных запусков нет.
